## 核心问题

数据怎么存？

## 本章简介

独特设计：以”断电安全”为主线贯穿文件系统选择、存储介质管理和应用层策略。有经验工程师知道ext4是常用文件系统、知道Flash有擦写次数限制、知道要用fsync保证数据落盘。但面对”选ext4还是f2fs还是UBIFS”“掉电后文件系统损坏怎么恢复”“为什么写小文件特别慢”“页缓存和回写的具体机制”这些实际问题时，需要源码级的理解。

本章的核心认知是：文件系统选择不是”哪个好”的问题，而是”你的存储介质、读写模式、可靠性需求组合最适合哪个”的匹配问题。断电安全不是文件系统自己的事——它是从应用层（fsync策略）到页缓存（回写策略）到文件系统（journal模式）到存储介质（FTL/MTD）的全链路设计。...
