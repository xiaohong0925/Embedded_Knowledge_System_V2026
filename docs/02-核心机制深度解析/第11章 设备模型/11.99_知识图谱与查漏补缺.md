## <span class="blue"> 本节导读

本章从总线-设备-驱动三角关系讲起，经 platform 驱动、compatible 匹配、sysfs 与 uevent，到设备树 overlay 收束，知识点分布在五个小节且互相咬合。本文件是全章的收束页：先用两张图把六大模块的结构关系和运行时调用链拉回整体视图，再给一份按主题分组的查漏补缺清单，逐条对照即可定位薄弱环节，回到对应小节补课。<BR>
本节覆盖：设备模型六大模块知识图谱、match→probe 与 overlay 加载两条调用链时序、覆盖全章的自检清单（按★标注重要度）。
