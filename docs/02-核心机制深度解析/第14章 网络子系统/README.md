## 核心问题

网络包怎么走？

## 本章简介

独特设计：以一个网络包的完整生命周期为主线，从网卡到用户空间逐层追踪。有经验工程师会用ifconfig配置网络、会用tcpdump抓包、知道socket编程的基本API。但面对”高负载下网络丢包怎么排查”“NAPI到底做了什么优化”“XDP和eBPF是什么关系”“网络栈的瓶颈在哪里”这些实际问题时，需要对网络子系统的源码级理解。本章的核心认知是：网络栈不是”一个管道”——它是一个多阶段流水线，每个阶段都有独立的优化空间和瓶颈特征。理解SKB在网络栈中的旅程、理解NAPI如何在高负载下保护CPU不被中断淹没、理解XDP如何在驱动层就做出转发决策，是优化嵌入式网络设备性能的关键。...
