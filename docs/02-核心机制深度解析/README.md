# 第 II 部：内核核心机制

> BIEM [I→E] | 从启动链到电源管理，逐行理解内核源码

---

## 核心价值

第 II 部是全书的技术深水区。经过第 I 部 "让系统跑起来" 的实战热身，你现在将潜入 Linux 内核源码，逐章、逐节、逐行理解内核子系统的工作机制。

完成本部分后，你将具备：
- **源码级理解**：能读懂内核关键函数、数据结构、设计决策
- **独立调试能力**：面对内核崩溃、调度异常、内存泄漏、中断延迟等问题，能定位根因
- **系统优化能力**：能针对特定场景（低功耗、实时性、吞吐量）调优内核参数、裁剪子系统
- **移植与评估能力**：能将主线内核移植到新 SoC，评估驱动兼容性，判断内核版本选型

## 与第 I 部的衔接

> **第 I 部 "让系统跑起来" → 第 II 部 "让系统跑得好"**

第 I 部（第1–6章）教会你：
- 认识开发板、搭建交叉编译环境
- 配置编译 U-Boot、Linux 内核、根文件系统
- 点亮第一个 LED，完成系统启动闭环

第 II 部在此基础上追问 **"为什么"** 和 **"怎么做"**：
- 启动链每一行代码在做什么？BootROM 如何加载 SPL？内核如何解析设备树？
- 进程调度如何选择下一个任务？CFS 的 vruntime 如何计算？
- 内存分配路径经过哪些数据结构？slab 如何管理对象缓存？
- 中断从 GPIO 引脚到用户空间的完整链路是什么？底半部如何选择？
- 设备模型的 kobject、kset、sysfs 如何映射？

## 与第 III 部的衔接

> **第 II 部理解内核机制 → 第 III 部编写设备驱动**

第 II 部让你"读懂内核"，第 III 部（设备驱动与总线）让你"写出让内核认可的代码"。

具体衔接关系：
- 第7章（启动链）的设备树解析 → 第 III 部所有驱动的 `.dts` 编写与调试
- 第8章（进程与调度）的 kthread、cgroup → 第 III 部驱动中的工作队列、资源隔离
- 第9章（内存管理）的 DMA、CMA → 第 III 部 DMA 缓冲区分配、流式/一致性映射
- 第10章（中断与时间）的 `request_irq()`、底半部 → 第 III 部中断处理函数设计
- 第11章（设备模型）的 `platform_driver`、`bus_type` → 第 III 部驱动注册框架
- 第12章（文件系统）的 `sysfs`、VFS → 第 III 部 `sysfs` 属性文件、调试接口
- 第13章（并发与同步）的 spinlock、mutex → 第 III 部驱动并发安全

- 第15章（电源管理）的 Runtime PM → 第 III 部驱动电源回调实现

## 螺旋学习模型

第 II 部采用 **螺旋上升** 的学习模型：

```
第7章 → 第8章 → 第9章 → 第10章 → 第11章 → 第12章 → 第13章 → 第14章 → 第15章
启动链  → 进程  → 内存  → 中断   → 设备   → 文件   → 并发   → 网络   → 电源
```

每一章都假定你已掌握前序章节的核心概念，但也会适时回顾关键知识点。例如：
- 第10章讲中断底半部时，会引用第8章的进程调度上下文
- 第13章讲并发时，会涉及第9章的内存屏障与页表一致性
- 第14章讲网络协议栈时，会用到第10章的 NAPI 中断机制

**建议**：按顺序阅读，不要跳章。如果某章感到吃力，可先完成该章的 "知识图谱与查漏补缺" 小节，再回到正文。
