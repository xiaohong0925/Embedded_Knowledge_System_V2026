# D. 驱动开发实战

> 扩展篇 D | 状态：建设中（Part 1 通用写法线逐篇落地中）

## 核心问题

第10/11/12/13/22章把机制都讲透了——但让我从零写一个能进产品的驱动，从哪行代码开始写起？

## 两条线

- **Part 1 通用写法线（D.1-D.9）**：任何驱动都绕不开的九件兵器——骨架、cdev/ioctl、等待与通知、中断、定时、内存与 DMA、设备树、电源管理、调试接口
- **Part 2 子系统框架线（D.10-D.18）**：进框架的写法，每篇一个真实外设场景 + "用现成驱动 vs 自己写"判定

## 贯穿案例：TS502

Part 1 采用贯穿案例：虚构 I2C 复合传感器芯片 TS502（温度寄存器 + 32 级采样 FIFO + 数据就绪中断脚 + PWM 报警输出）。D.1 从空骨架起步，每篇加一块拼图，终点是约 400 行的产品级模板驱动。寄存器手册附在 D.1，后续各篇直接引用。

## 阅读前提

- 主线第10章（中断与时间）、第11章（设备模型）、第12章（文件系统 12.1 节）、第13章（并发与同步）的机制部分
- 本篇不重复机制原理，只讲写法；每篇开头的「与第 N 章的分工」声明写清边界
