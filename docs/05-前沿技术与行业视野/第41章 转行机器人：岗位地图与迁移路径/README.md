# 第41章：转行机器人：岗位地图与迁移路径（附加章节）

> 所属：第 五 部 前沿技术与行业视野

> 难度：[E] | 核心问题：3 年以上的嵌入式工程师进机器人行业，去哪个岗位、差距在哪、怎么走？

## 核心问题

写给 3/5/8/10+ 年嵌入式软件工程师的机器人行业转行专题。不是行业科普（产业链全景见第 39 章），不是通用职业规划（路线图框架见第 38 章）——本章是通用路线图在机器人行业的具体化：八个岗位族地图、技能平移矩阵、四个人群各自的迁移策略与完整案例。

## 本章简介

2026 年机器人行业的真实缺口不是"会 ROS2 的人"——那已是 JD 标配。供不应求的是三类硬方向：电机控制与伺服驱动、实时系统与底层软件、边缘计算与异构部署。本章按"行业真相速览 → 八岗位族地图 → 技能平移矩阵 → 3/5/8/10+ 年四个人群各一节策略 → 四个完整转行案例 → 避坑清单"展开，每节给出带时间线的行动表。

制作方式：按本书设计稿由外部 AI 集群生成初稿，项目方完成薪资/行业数据复核与本书章节指针填充。薪资数据均标注来源（猎聘 2026-06 等公开样本），案例为合成脱敏人物，标注【待核实】处需人工补证。
