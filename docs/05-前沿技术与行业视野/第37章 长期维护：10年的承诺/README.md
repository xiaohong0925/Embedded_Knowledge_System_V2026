## 核心问题

怎么维护一个系统10年？

## 本章简介

核心问题：工业产品生命周期通常10年+，远超标准LTS内核的2-6年。如何管理一个需要维护10年的嵌入式Linux产品？

本章回答三个问题：

1. 长期内核维护的选择有哪些？
2. CVE管理流程如何建立？
3. 如何控制技术债务，避免维护成本随时间指数增长？

CIP（Civil Infrastructure Platform）项目：SLTS内核维护10+年，基于Debian的参考镜像，自动化验证测试，满足IEC 62443-4网络安全标准，SWUpdate+TUF安全更新。

里程碑：CIP首个SLTS内核基于Linux 4.4，从2016年维护到2027年1月，证明了联盟可以成功维护内核十年。
