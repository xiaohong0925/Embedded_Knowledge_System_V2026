## 本章简介

核心问题：作为一名3-8年经验的嵌入式Linux工程师，你的下一步应该走向哪里？如何制定个人技术路线图？

本章回答三个终极问题：

1. 哪些技能在升值，哪些在贬值？
2. 专家/管理/架构三条路径怎么选？
3. 如何制定可执行的个人技术路线图？

中国嵌入式Linux薪资参考（2025年）：人才缺口约180万，新能源汽车人才缺口超百万，70%的嵌入式岗位要求AI相关技能。

三条路径：专家路径（技术权威）、管理路径（工程经理→总监→VP）、架构路径（系统架构师→首席架构师）。选择取决于个人兴趣、组织需求和市场趋势。
