## 核心问题

怎么在一颗芯片上跑多个系统？

## 本章简介

核心问题：如何在同一个SoC上同时运行Linux和RTOS？不同虚拟化方案怎么选？

本章回答三个关键决策问题：

1. 什么时候需要虚拟化/混合部署？单Linux不行吗？
2. Jailhouse/Xen/KVM各适合什么场景？
3. 汽车域控制器架构如何影响技术选型？

传统嵌入式系统中，一个处理器运行一个OS。但随着SoC性能提升和功能安全要求提高，出现了"一个SoC运行多个OS"的需求。

Jailhouse静态分区模型：硬件资源被静态划分为多个cell（分区），每个cell独占资源。适合确定性要求高的场景。

Xen DOM0/DOMU模型：Xen Hypervisor作为最优先运行层，DOM0管理其他DOMU。适合需要灵活资源管理的场景。
