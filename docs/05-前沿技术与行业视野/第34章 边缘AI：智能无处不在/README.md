## 核心问题

嵌入式设备怎么跑AI推理？

## 本章简介

核心问题：AI推理如何部署到嵌入式设备上？NPU驱动架构是什么？嵌入式系统设计因为AI发生了哪些根本变化？

本章回答三个问题：

1. 嵌入式设备上的AI推理技术栈是什么？
2. NPU（神经网络处理单元）如何与Linux集成？
3. AI能力如何改变嵌入式系统的整体设计思路？

早期方案（每家一套）：SoC厂商提供闭源SDK → 用户空间库 → 自定义ioctl → 内核驱动。问题：每个SoC完全不同，无兼容性。

当前方案（标准化中）：用户空间推理框架（TFLite/ONNX Runtime/ExecuTorch）→ 统一驱动接口 → 厂商NPU驱动 → 硬件。
