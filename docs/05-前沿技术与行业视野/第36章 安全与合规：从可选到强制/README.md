## 本章简介

核心问题：EU Cyber Resilience Act和其他安全法规如何改变嵌入式产品开发？你需要做什么来合规？

本章回答三个问题：

1. EU CRA和其他安全法规的具体要求是什么？
2. 功能安全（ISO 26262/IEC 61508）与信息安全的融合趋势
3. 这些法规如何实质性地改变产品设计流程？

EU Cyber Resilience Act（CRA）核心要求：产品必须满足安全设计、漏洞管理、更新机制等要求。不合规后果：罚款1500万欧元或全球年营业额2.5%（取高者），产品撤出欧盟市场，公开警告。

后量子密码学（PQC）时间表：NIST已标准化ML-KEM、ML-DSA、SLH-DSA算法。2025-2028了解评估，2028-2030混合方案，2030-2035全面迁移。OpenSSL 3.2+已支持，但小设备上性能开销大（签名验证慢10-100x）。
