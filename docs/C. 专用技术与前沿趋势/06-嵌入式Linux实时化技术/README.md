## 模块概述

嵌入式 Linux 在工业控制、机器人、汽车电子等场景需要**确定性实时响应**——任务必须在严格的时间约束内完成。本模块覆盖 Linux 实时化的核心技术：

- **PREEMPT_RT**：内核抢占补丁，将 Linux 变为软实时操作系统
- **Xenomai**：双核方案，在 Linux 旁运行实时核
- **deadline 调度**：SCHED_DEADLINE 的带宽保障机制
- **确定性分析**：实时性测试、延迟测量与优化
