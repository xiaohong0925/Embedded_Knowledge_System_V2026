# 第1章：认识你的开发板

> 所属：第 I 部 系统启动与运行
> BIEM：[B] | 核心问题：板子上有什么？怎么连？怎么启动？

## 核心问题

拿到一块陌生的嵌入式开发板，你能否在 30 分钟内识别出关键器件、建立物理连接、上电并看到启动信息？这是每一个嵌入式开发者的第一课。

## 学习目标

完成本章后，你应该能够：

- 识别开发板上的 SoC、存储、电源、接口等关键器件
- 建立串口连接，使用终端工具与开发板交互
- 上电后观察并解读 BootROM / Bootloader 的输出信息
- 阅读原理图和开发板手册，定位器件和信号

## 前置知识

- 无。本章从完全零基础开始。
- 具备基本的 Linux 命令行使用经验会有帮助，但不是必需。
