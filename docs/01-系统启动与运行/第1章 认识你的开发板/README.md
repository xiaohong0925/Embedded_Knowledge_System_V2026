# 第1章：认识你的开发板

> 所属：第 一 部 系统启动与运行
> BIEM：[B] | 核心问题：板子上有什么？

## 核心问题

板子上有什么？

## 本章简介

你拿到一块全新的开发板，包装盒里有板子、电源线、几份图纸。你的目标是让它跑起Linux。但在按下电源键之前，你需要回答几个根本问题：这块板子用的是什么处理器？代码存在哪里？我怎么知道它有没有在运行？如果这些问题不搞清楚，后续所有工作都是盲目的。很多嵌入式教材会在这时展开”计算机组成原理”的宏伟大厦——CPU流水线、Cache一致性、总线协议……但那些知识在bring-up阶段用不上。

本章采用”够用即可”策略：只学开箱立刻需要知道的硬件知识，把深度留给后续螺旋上升时解决。学完这一章，你应该能看懂开发板原理图的关键部分、判断电源和串口连接是否正确、理解板子上的存储芯片各自承担什么角色。这是整个嵌入式Linux旅程的物理起点。前置知识：无。这是全书的第一章，从物理世界开始。...
