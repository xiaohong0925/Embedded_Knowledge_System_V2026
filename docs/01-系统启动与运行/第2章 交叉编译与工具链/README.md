# 第2章：交叉编译与工具链

> 所属：第 I 部 系统启动与运行
> BIEM：[B→I] | 核心问题：怎么在 PC 上编译板子程序？

## 核心问题

你的 PC 是 x86 架构，开发板是 ARM（或其他）架构。如何在 PC 上编译出能在开发板上运行的程序？这就是交叉编译。理解工具链的组成、配置和使用，是后续编译 U-Boot、内核、BusyBox 的基础。

## 学习目标

完成本章后，你应该能够：

- 理解交叉编译与原生编译的区别，解释 Target Triple 的含义
- 识别工具链的三大组件：gcc、binutils、libc
- 理解 sysroot 的作用和目录结构
- 安装、配置并验证一套可用的交叉编译工具链
- 独立完成第一个交叉编译程序的编译、部署和运行
