# 第4章：内核配置与编译

> 所属：第 I 部 系统启动与运行
> BIEM：[B→I] | 核心问题：怎么让内核支持我的板子？

## 核心问题

Linux 内核源码包含数百万行代码，支持数千种硬件。如何从中选出你需要的部分，编译出一个能在你的开发板上运行的内核？理解 Kconfig、menuconfig、defconfig 和各种内核镜像格式，是本章的核心。

## 学习目标

完成本章后，你应该能够：

- 获取合适的内核源码版本，理解目录结构
- 使用 Kconfig / menuconfig 配置内核，理解依赖关系
- 掌握 defconfig 的使用和 savedefconfig 的保存方法
- 理解 vmlinux、Image、zImage、uImage、dtb 的区别和用途
- 配置 ARCH 和 CROSS_COMPILE，编译出内核、设备树和模块
- 区分驱动编译进内核与编译成模块，能手动加载模块
