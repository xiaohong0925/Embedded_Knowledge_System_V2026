## 核心问题

内核启动后怎么得到shell？

## 本章简介

内核启动后做的第一件事是挂载根文件系统（rootfs），然后执行第一个用户空间程序（init）。没有根文件系统，内核启动后就会panic， 它是一个操作系统，但没有任何用户可以使用的工具（没有ls、没有echo、没有shell）。根文件系统是用户空间的”宇宙大爆炸”起点。

很多初学者能成功编译内核但卡在”kernel panic - not syncing: No working init found”， 不是内核问题，是根文件系统缺失或损坏。本章的核心目标是：让读者理解根文件系统的组成和作用，使用BusyBox构建最小但完整的最小系统，编写初始化脚本，最终看到shell提示符。那一刻的意义不仅是技术成功， 你从零开始，让一块裸板产生了能与你交互的shell。

这是整个第一部的高潮。前置知识：第3章（U-Boot传递bootargs指定rootfs位置）、第4章（内核需要配置文件系统支持）。...
