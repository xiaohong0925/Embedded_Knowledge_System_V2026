# 第5章：根文件系统与初始化

> 所属：第 I 部 系统启动与运行
> BIEM：[B] | 核心问题：内核启动后怎么得到 shell？

## 核心问题

Linux 内核启动的最后一步是挂载根文件系统并执行 init。如果没有根文件系统，内核会 panic。本章教你如何手工构建一个最小的 BusyBox 根文件系统，配置 init 进程，最终看到熟悉的 `#` 提示符。

## 学习目标

完成本章后，你应该能够：

- 理解根文件系统对内核启动的必要性，认识 init 进程的角色
- 按照 FHS 标准创建最小根文件系统目录结构
- 配置、编译并安装 BusyBox，构建实用工具集
- 创建必要的设备节点（devtmpfs 或手动 mknod）
- 编写 inittab 和 init 脚本，配置串口登录
- 最终看到 shell 提示符，执行基本命令
