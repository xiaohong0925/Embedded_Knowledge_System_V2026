# 第3章：Bootloader：系统的第一段代码

> 所属：第 I 部 系统启动与运行
> BIEM：[B→I] | 核心问题：上电后谁加载内核？

## 核心问题

开发板上电后，CPU 从什么地址开始执行？BootROM 是什么？SPL 是什么？U-Boot 如何被加载？又如何加载 Linux 内核？理解 Bootloader 的启动链，是掌握系统启动全过程的关键一环。

## 学习目标

完成本章后，你应该能够：

- 描述 BootROM → SPL → U-Boot → Linux 的完整启动链
- 理解 BootROM 的启动介质选择机制和 SPL 的作用
- 配置、编译 U-Boot 并烧录到开发板
- 使用 U-Boot 命令行进行内存、存储、网络、启动操作
- 理解设备树的基本概念，能通过 U-Boot 启动内核
