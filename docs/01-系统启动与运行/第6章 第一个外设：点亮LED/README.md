# 第6章：第一个外设：点亮LED

> 所属：第 一 部 系统启动与运行
> 
> BIEM：[B] | 核心问题：怎么让软件控制硬件？

## 核心问题

怎么让软件控制硬件？

## 本章简介

shell提示符出现了，但这还不够， 嵌入式系统的本质是与物理世界交互。<br>LED是最简单、最直观、最不容易出错的外设实验。从用户空间控制LED，再过渡到编写第一个设备树节点加载内核驱动，这个过程让读者第一次体验到”软件控制硬件”的快感。如果第一部在shell处戛然而止，读者会有”然后呢？“的空虚感。第6章回答这个问题：然后你可以控制硬件了。

同时，本章的设计巧妙之处在于， 它通过一个最简单的外设（LED），让读者预览了后续三部将要深入的主题：GPIO子系统（第II部驱动开发）、设备树绑定（第II部设备模型）、sysfs接口（第III部用户空间接口）。这是一个”尝一口，知道味道”的章节，建立对后续学习的期待。

前置知识：第5章的shell环境（需要能在板子上执行命令）、第3章的设备树基础（理解.dts语法）、第1章的GPIO物理概念。
