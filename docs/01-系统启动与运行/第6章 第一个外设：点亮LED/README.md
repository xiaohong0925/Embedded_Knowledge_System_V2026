# 第6章：第一个外设：点亮LED

> 所属：第 I 部 系统启动与运行
> 
> BIEM：[B] | 核心问题：怎么让软件控制硬件？

## 核心问题

系统已经启动，shell 已经就绪。现在要做的是让软件真正控制硬件——从点亮一颗 LED 开始。本章从用户空间 sysfs 接口出发，初步接触 GPIO 子系统、设备树和内核驱动框架，为第 II 部的驱动开发埋下伏笔。

## 学习目标

完成本章后，你应该能够：

- 理解 GPIO 子系统的基本概念，从用户空间通过 sysfs 控制 GPIO
- 编写设备树节点描述 LED 硬件连接
- 初步了解内核 LED 驱动框架的存在和作用
- 通过多种方式（sysfs、设备树驱动）点亮和熄灭 LED
- 建立「软件 → 驱动 → 硬件」的第一直觉
