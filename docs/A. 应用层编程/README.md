## 模块概述

本模块是嵌入式 Linux 知识体系的**应用层能力层**，聚焦用户态程序开发。从 POSIX 多线程编程、进程间通信、Socket 网络编程，到嵌入式容器化（Docker/Podman）和系统服务设计。应用层是系统能力的使用者——理解内核提供的接口、驱动暴露的设备节点，并编写高效、可靠的用户态程序。

与第 I-V 部的关系：**应用层是系统能力的使用者**。内核提供资源管理，驱动提供硬件抽象，而应用层则是将这些能力转化为用户价值的最终环节。
