## 1. 大纲对第 18 章的设计意图（docx 原文摘要）

- **核心决策问题**："Yocto 还是 Buildroot？怎么设计长期可维护的构建流程？"
- **核心洞察**（本章灵魂句）：构建系统的选择不是技术偏好问题，而是**组织性决策**——影响团队速度、镜像大小、安全姿态、合规能力、长期维护成本；**真实成本不在初始设置，而在 5 年后的维护**。
- **决策场景（2026-09-07 用户两轮拍板定行业：机器人整机厂商）**：机器人公司构建系统负责人——3 个产品线（AMR 搬运机器人、协作机械臂、人形/复合机器人）5 个 SKU 全基于 Yocto；合规压力来自欧盟 CRA（2027 全面执法，覆盖一切含数字元素的产品）+ 大客户（汽车厂/3PL 仓库）把 IEC 62443 工业网络安全审计写进采购合同，SBOM 与 CVE 处置承诺成为投标硬门槛；ROS 2 + 导航栈 + 视觉模型的 x86 仿真 + Jetson/ARM 双架构构建，CI 全量 4 小时、工程师每天多次等待；人形新品线抢窗口期，评估 Buildroot"快速启动"。要决策：统一还是混用？CI 怎么优化？Layer/Recipe 怎么组织 5 个 SKU 的共享与差异？
  - 行业边界说明：功能安全（IEC 61508/ISO 10218）属运行时安全，归第 19/30 章，本章合规只讲软件供应链侧（SBOM/CVE/62443 审计）。
  - 演变记录：大纲原场景为医疗设备公司（FDA 510(k) 形态）→ 第一轮改数通仪器仪表+PCIe 加速卡（用户判定行业偏窄否决）→ 定稿机器人整机厂商。大纲医疗场景保留为 18.6 三案例之一（FDA = 合规驱动选型的极端参照）。
- **大纲给定 5 节**：18.1 Yocto vs Buildroot vs OpenWrt 决策矩阵 / 18.2 长期维护成本（TCO）分析 / 18.3 Layer/Recipe 组织最佳实践 / 18.4 CI/CD 流水线设计 / 18.5 开源合规与 SBOM 管理。
- **大纲给定资产**：选项分析（构建系统 5 种 + CI 策略 4 种 + 合规选项 4 种）、两张 Trade-off 大表（13 维三系统对比 + 7 特性对比）、两棵决策树（产品复杂度×团队规模；合规需求）、评审清单 4 组 20 项、三个案例（医疗设备 Yocto/FDA、IoT 传感器 Buildroot/2 周上市、Buildroot→Yocto 迁移/2 人 4 个月）。
- **第三部章模板（9 固定块）**：核心决策问题 → 为什么需要 → 决策场景 → 选项分析 → Trade-off → 决策树 → 评审清单 → 案例研究 → 各小节详述。

## 3. 本章独有领土（写厚的地方）

1. **组织性决策视角**——构建系统选型 = f(团队规模, 产品线数量, 合规要求, 上市时间)，不是技术参数对比。这是全书第一个把"团队和组织"作为一等决策变量的章。
2. **TCO 量化模型**——大纲核心洞察的载体：初始成本 + 学习成本 + 构建时间×次数 + 5 年维护。技术债务的具体形态（local.conf 膨胀、recipe 拷贝粘贴、Layer 循环依赖）。
3. **Yocto Layer/Recipe 工程实战**——第一部和 16 章都不曾进入的深水区：Layer 分层模板、bbappend 纪律、SRC_URI 补丁管理、多 SKU 的 MACHINE 驱动差异。
4. **CI/CD 的嵌入式特殊性**——构建时长、硬件在环测试（HIL）、sstate 缓存架构、分层触发策略。通用 CI 知识不稀缺，嵌入式 CI 的硬件依赖与小时级构建才是独有内容。
5. **开源合规工程化**——SBOM 三格式（SPDX/CycloneDX/SWID）、cve-check、copyleft 隔离架构。2026 年欧盟 CRA 进入执法倒计时，这是"法律要求变商业要求"的时代性内容。
6. **三案例 + 评审清单**——决策场景收口。

## 4. 时代性更新（写作时必须联网核实，禁止凭记忆）

- **Yocto LTS 现状**：写作时确认当前 LTS 版本（5.0 scarthgap 之后）、支持周期、binutils/gcc 基线。
- **cve-check 变迁**：Yocto 5.x 起 cve-check 默认行为与 CVE 数据库来源变化（NVD API 限流、Vulns 类替代），需核实。
- **EU CRA 执法时间线**：2027 年强制合规节点，SBOM 从"加分项"变"入场券"。
- **SPDX 3.0 / CycloneDX 现状**、kas/容器化构建的事实标准地位。
- 原则：**版本号、法规日期、工具默认值一律写作时现查**；查不到的用"以官方文档为准"话术，不留具体数字。
