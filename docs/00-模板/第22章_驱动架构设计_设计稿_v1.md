## 3. 本章独有领土（写厚的地方）

1. **量化决策维度**——延迟 <1ms 必须内核、中断频率 >100Hz 建议内核、电池供电必须内核 PM、原型期用户空间更快。把"内核还是用户空间"从信仰之争变成可计算的问题。这是全书第一个把驱动放置决策量化的章。
2. **驱动之间的关系设计**——本章核心洞察的载体：错误分级策略的统一性（L1~L4 全驱动一致）、电源依赖图（设备 B 依赖设备 A 供电的图结构）、热插拔的统一姿态。单驱动写法在 D 篇，**驱动间的契约**只在本章。
3. **HAL 位置决策**——内核子系统 / 用户空间 HAL / D-Bus 服务 / sysfs 裸暴露，四位置的选择矩阵与迁移路径。这是 8 SKU 重构案例（60%→<10%）的理论载体。
4. **总线的架构后果**——不是协议怎么工作（B 扩展），而是"选 I2C 意味着接受单点瘫痪域，所以总线恢复机制是架构必选项"这类选型→架构约束的传导链。
5. **多媒体 pipeline 决策**——V4L2 vs libcamera、atomic commit、DMA-BUF 零拷贝、带宽预算分配。全书独有，决策级深度。
6. **三案例 + 20 项评审清单**——决策场景收口（22.6 新增，与 17.6/18.6 同构）。
