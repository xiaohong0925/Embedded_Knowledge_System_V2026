## 一、实战篇定位说明（代码级产品实战）

| 层级 | 归属 | 回答的问题 |
|------|------|-----------|
| 协议原理 | B 扩展本篇 | 这个总线是什么、怎么工作 |
| 驱动写法 | D 扩展 | 驱动写法体系：机制、套路、各种驱动模型怎么写 |
| **代码级产品实战** | **B 扩展实战篇** | 拿一个真实器件做端到端案例：数据手册 → 协议/时序 → 设备树 → 驱动代码 → 应用代码 → 联调 |
| 系统级协同 | B-E 综合实战 | 整机多总线怎么选型、怎么协同 |

实战篇统一结构：

1. **绑定真实器件**：每篇选 1 个经典量产器件（如 I2C 选 AT24C02 EEPROM、SPI 选 W25Qxx Flash），不用虚构芯片
2. **从数据手册出发**：读时序图、寄存器表、命令集——主线是"协议怎么落地成代码"
3. **端到端贯通**：设备树描述 → 驱动代码（框架机制引 D 扩展对应篇，不重复展开）→ 应用层代码 → 联调验证
4. **无硬件后备**：给出 QEMU/模拟器或开发板互换角色的替代路径；示波器波形仅作辅助印证，不作为主线

## 二、PCIe 系列扩编方案

原 B-C.11 三篇（基础/枚举配置空间/Linux 驱动与 DMA）保留并全部重写，新增三篇：

- **PCIe 进阶**：Gen4/5/6 速率演进、信号完整性（均衡、通道裕量）、AER 错误处理、热插拔——吸收原 B-F.16.2「当代 PCIe」
- **CXL 与 PCIe 生态扩展**：CXL.io/CXL.cache/CXL.mem、内存池化、Switch 与 Retimer——吸收原 B-F.16.3
- **PCIe 卡实战**：EP 卡 BAR 访问与 DMA 驱动开发全流程（代码级）——面向 PCIe 卡工程师岗位
