# B-B.8.1 MIPI D-PHY物理层

>
> 难度：[I] Intermediate | 预计阅读时间：35分钟

## <span class="blue"> 本节导读

MIPI D-PHY是移动设备摄像头和显示屏的物理层 backbone。你手里的手机，后置摄像头拍的那张照片，就是通过 D-PHY 的差分线从传感器"跑"到 SoC 的。本节我们会拆解 D-PHY 的物理信号构成——1对时钟 + 最多4对数据，搞懂它独特的双模式设计（LP 低速控制 / HS 高速传输），以及从 LP 切入 HS 那个关键的状态机跳转。后面还会对比 C-PHY、A-PHY，帮你在选型时快速判断哪种 PHY 适合自己的产品。

读完本节，你应该能：
- 画出 D-PHY 的 Lane 构成和数据通路
- 解释 LP-11 → HS 的完整切换流程
- 根据 Lane 数和产品分辨率估算带宽是否够用
- 在 D-PHY / C-PHY / A-PHY 之间做初步选型

---

## <span class="blue"> D-PHY架构：时钟+数据的差分对设计 [I]

D-PHY 的物理连接采用**源同步**架构——发送方自己带时钟，接收方靠这个时钟采样数据。整个链路最少需要以下信号：

```
        发送端 (CSI-2: 摄像头 / DSI: 显示屏)              接收端 (SoC)
        ┌─────────────────────────┐                    ┌─────────────────┐
        │                         │    CLK+ ────────►  │                 │
        │    ┌─────────────┐      │    CLK- ────────►  │    D-PHY        │
        │    │             │      │                    │    接收器        │
        │    │   数据源     │◄─────┤    D0+ ────────►  │    (含CDR)      │
        │    │  (Sensor/   │      │    D0- ────────►  │                 │
        │    │   GPU)      │      │    D1+ ────────►  │                 │
        │    │             │      │    D1- ────────►  │                 │
        │    └─────────────┘      │    D2+ ────────►  │                 │
        │                         │    D2- ────────►  │                 │
        │    1×CLK pair           │    D3+ ────────►  │                 │
        │    + 1~4×Data pairs     │    D3- ────────►  │                 │
        └─────────────────────────┘                    └─────────────────┘
```

- **CLK+/-**：1对差分时钟，HS 模式下所有 Data Lane 共用这组时钟做边沿采样。
- **D0+/- ~ D4+/-**：最多4对差分数据线。D0 比较特殊，它在 LP 模式下还承担双向通信的角色（BTA，Bus Turn-Around）。

### 双模式：LP 与 HS

D-PHY 最 clever 的设计就是**双模式**——同一对物理线，既能低速传控制信令，又能高速传图像数据。

| 特性 | LP 模式 (Low Power) | HS 模式 (High Speed) |
|------|--------------------|---------------------|
| 信号方式 | 单端信号 | 差分信号 |
| 电压摆幅 | 1.2V (0~1.2V) | 200mV (典型) |
| 速率 | < 10 Mbps | 80 Mbps ~ 2.5 Gbps/lane |
| 用途 | 控制、配置、状态机切换 | 有效数据传输 |
| 功耗 | 极低 | 较高 |
| 线路状态 | LP-00/01/10/11 | HS-0/1 (差分) |

LP 模式下，每根线独立驱动为 0V 或 1.2V，四种组合构成状态机的四个基本状态。HS 模式下，两根线反相摆动，差分电压约 ±200mV，速率由协议版本和硬件能力决定。

> 💡 **提示**：MIPI 走线必须**等长匹配**（Lane 间长度差 &lt; 0.2mm），差分阻抗控制在 **100Ω ±10%**。PCB layout 时 CLK 与 Data Lane 之间保持 3W 间距，远离高速开关电源，这些约束直接影响眼图质量和链路稳定性。很多 MIPI 信号完整性问题不是芯片问题，而是板子没画好。

## <span class="blue"> LP模式状态机：从Stop到HS的切换流程 [I]

D-PHY 协议定义了一套精密的 LP 状态机，管理链路的启停、方向切换和模式转换。理解这个状态机是调试 MIPI 链路的基础。

### LP线路电平与状态定义

| 状态 | Dp 电平 | Dn 电平 | 含义 |
|------|---------|---------|------|
| LP-11 | 1 | 1 | **Stop** — 空闲状态，链路复位后的默认态 |
| LP-00 | 0 | 0 | **HS-Rqst** / Escape — 请求进入 HS 模式，或 Escape 命令入口 |
| LP-01 | 0 | 1 | **HS-Rqst-0** — 中间过渡态，配合状态机跳转 |
| LP-10 | 1 | 0 | **HS-Rqst-1** — 中间过渡态，配合状态机跳转 |

> 电平说明：1 = 1.2V，0 = 0V。LP 模式为单端驱动，每根线独立判断。

### LP → HS 切换时序

整个切换过程必须严格按协议规定的序列进行，任何违规跳变都会导致接收端拒绝进入 HS 模式。

```
时间轴 ──────────────────────────────────────────────────────────────►

CLK+/-:  LP-11(Stop)    LP-00     HS-Rqst    HS-0/1 差分突发      LP-11
         ────────      ─────    ─────────   ╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱╲╲╱╲╱  ────────
                                        ───╱                    ╲───────
         (空闲)         (请求)   (准备)   (高速差分传输开始)

D0+/-:   LP-11(Stop)    LP-01 → LP-00   HS-Rqst   HS-0/1 差分突发   LP-11
         ────────      ───┬──── ─────  ─────────  ╱╲╱╲╱╲╱╲╱╲╱╲╱╲╱  ────────
                         │                    ───╱                  ╲───────
         (空闲)      (中间态)  (中间态)   (准备)   (数据突发)

状态:    STOP                ▼        ▼       ▼         HS-ACTIVE          STOP
                                 LP → HS 切换完成，Payload 传输开始

关键时序参数：
  ├─ T_LPX    : LP 状态持续时间（最小50ns）
  ├─ T_HS-PREPARE : HS 准备时间（38~95ns + 2UI）
  ├─ T_HS-ZERO    : HS 零态持续时间（105ns + 6UI）
  └─ T_HS-TRAIL   : HS 结尾拖尾时间（最大105ns + 12UI）
```

### 切换流程逐步解析

1. **LP-11 (Stop)** — 链路空闲态。此时 PHY 处于低功耗状态，差分驱动器关闭。

2. **LP-11 → LP-00** — 发送方拉低两条数据线，表示要搞事情了。接收端检测到 LP-00 后开始监控后续序列。

3. **LP-00 → LP-01 → LP-00 (Data Lane)** — Data Lane 上这组特定序列是 HS 请求签名。CLK Lane 走 LP-00 → HS 请求路径。

4. **HS-Rqst → HS-0/1 突发** — 驱动器从单端模式切换为差分模式，开始发送 HS preamble（一串 0），然后是同步字（0xB8），最后才是实际的 CSI-2 / DSI 数据包。

5. **HS-TRAIL → LP-11 (Stop)** — 数据传输完毕后，发送 trailing bits，关闭差分驱动，回到 LP-11 空闲。

> ⚠️ **陷阱**：D-PHY 的 HS 模式是**突发传输 (burst)** 架构——链路的典型生命周期是 LP → HS → LP → HS → LP。每次从 LP 切入 HS 都有固定开销（LP 唤醒序列 + HS preamble + Sync 字，约几百纳秒）。这意味着**小包传输效率极低**。如果你用 MIPI 传大量小数据包（比如稀疏的传感器事件），协议开销会吃掉大量带宽。摄像头和显示屏之所以适合 MIPI，正是因为它们的图像数据天然是大包连续流。

## <span class="blue"> D-PHY版本演进与参数 [M]

| 参数 | v1.1 | v1.2 | v2.0 | 说明 |
|------|------|------|------|------|
| 最高速率/lane | 1.5 Gbps | 2.5 Gbps | 4.5 Gbps | v2.0 主要面向高分辨率显示器 |
| 最少 Lane 数 | 1 Data | 1 Data | 1 Data | CLK 始终至少1对 |
| 最多 Lane 数 | 4 Data | 4 Data | 4 Data | 多 Lane 可并行扩展带宽 |
| LP 模式速率 | <10 Mbps | <10 Mbps | <10 Mbps | LP 速率基本不变，够传控制信令即可 |
| 电压摆幅(HS) | 200mV | 200mV | 200mV | 差分摆幅，降低 EMI |
| 电压摆幅(LP) | 1.2V | 1.2V | 1.2V | 单端 CMOS 电平 |
| 链路方向 | 半双工 | 半双工 | 半双工 | D0 可 BTA 反向，但非全双工 |
| 主要应用 | 720p 摄像头 | 1080p/4K 摄像头 | 4K/8K 显示屏 | 版本与分辨率需求匹配 |

实际项目中，v1.2 是目前嵌入式领域最常见的规格——4 Lane 下总带宽 10Gbps，足够带 4K@30fps 的摄像头（未压缩 RAW12 约需 8.9Gbps，刚好够）。如果要推 4K@60fps 或者高帧率多路，就需要考虑 4 Lane v2.0 或转向 C-PHY。

## <span class="blue"> Lane数量与带宽计算 [I]

D-PHY 的总带宽 = Lane 数 × 每 Lane 速率。这是做方案选型时最先算的一笔账。

### 带宽与Lane数关系

```
带宽对比 (D-PHY v1.2 @ 2.5Gbps/lane)

1 Lane:   CLK+/-  +  D0+/-
          └─────────────────┘
          2.5 Gbps  ──────►  约 312 MB/s 有效带宽
          
          适用：QVGA 小传感器，低速控制通道

2 Lane:   CLK+/-  +  D0+/-  +  D1+/-
          └──────────────────────────┘
          5.0 Gbps  ──────►  约 625 MB/s 有效带宽
          
          适用：720p@60fps，1080p@30fps 摄像头

4 Lane:   CLK+/-  +  D0+/-  +  D1+/-  +  D2+/-  +  D3+/-
          └─────────────────────────────────────────────────┘
          10.0 Gbps  ──────►  约 1.25 GB/s 有效带宽
          
          适用：1080p@120fps，4K@30fps 摄像头，2K 显示屏
```

> 有效带宽按 8b/10b 编码开销和协议头开销折算，约为总物理带宽的 80%。

### 实际选型速算

举个例子：你要接一颗 1080p (1920×1080) 的摄像头， Bayer RAW10 输出，30fps。

```
像素时钟 = 1920 × 1080 × 30fps = 62.2 Mpixel/s
数据率   = 62.2M × 10bit = 622 Mbps
         
加 15% 消隐(blanking)开销: 622 × 1.15 ≈ 715 Mbps

结论：1 Lane D-PHY v1.1 (1.5Gbps) 理论够，但裕量不足；
      2 Lane 方案最稳妥，且给 ISP 后处理留带宽空间。
```

如果同样是这颗摄像头，改成 60fps，数据率翻倍到 1.43Gbps，那就必须用 2 Lane 以上了。

## <span class="blue"> C-PHY与A-PHY：D-PHY的两种进化方向 [M]

MIPI Alliance 在 D-PHY 之后推出了两条技术路线，分别解决不同的痛点：

### 三线制 C-PHY

C-PHY 取消了独立的 CLK Lane，采用 **3-wire symbol encoding**（3线符号编码）：

- 3根线一组（没有 CLK），编码方式为 **transition-based**，利用线间电平差表示符号
- 每个 symbol 映射到 16-bit 数据中的 7 位（约 2.28 bits/symbol）
- 时钟信息嵌入在符号跳变中，接收端从数据流恢复时钟

| 维度 | D-PHY | C-PHY | A-PHY |
|------|-------|-------|-------|
| 信号线结构 | 1 CLK pair + 1-4 Data pairs | 3-wire groups (无独立CLK) | 同轴/屏蔽双绞线 |
| 每 Lane 线数 | 2 (差分对) | 3 (三线组) | 1-2 |
| 编码方式 | 差分 + 8b/10b | 5b/7b 过渡编码 | PAM4 + FEC |
| 最高速率 | 2.5Gbps/lane (v1.2) | 2.5Gsym/s/lane ≈ 5.7Gbps | 16Gbps |
| 传输距离 | &lt;30cm (PCB/FFC) | &lt;30cm (PCB/FFC) | **15m** |
| 典型应用 | 手机摄像头/屏幕 | 高像素多摄手机 | 车载摄像头 (ADAS) |
| EMI 特性 | 良好 | 更好 (三线共模抵消) | 优 (长距离设计) |
| 与 D-PHY 兼容 | 基准 | 不兼容 (新 PHY) | 不兼容 |

> 💡 **提示**：C-PHY 的 "lane" 概念和 D-PHY 不同——CPHY 的一个 lane 是 3 根线，而不是 2 根。算总带宽时别搞混了线数和 lane 数。3 组 C-PHY lane 需要 9 根线，而 4 Lane D-PHY 需要 10 根线（2×CLK + 2×4 Data），C-PHY 在 pin 效率上确实有优势。

### 长距离 A-PHY

A-PHY 是 MIPI 为**车载**场景设计的全新 PHY：

- **距离**：支持最长 15 米同轴电缆或屏蔽双绞线 (STP)
- **抗干扰**：内置强大的 FEC（前向纠错）和重传机制，适应汽车内恶劣的电磁环境
- **速率**：单链路最高 16Gbps，可满足多路 4K 摄像头同步传输
- **桥接**：通过 "A-PHY 转 CSI-2" 桥接芯片，现有 CSI-2 传感器可以无缝接入车载长距链路

A-PHY 的链路架构：

```
  摄像头模组                              中央网关/SoC
┌──────────────┐    同轴电缆(最长15m)    ┌──────────────────┐
│  MIPI CSI-2  │    ┌──────────────┐     │  A-PHY 接收器    │
│  传感器 ─────┼───►│   A-PHY TX   ├────►│   (解串器)        │
│  (D-PHY输出)  │    │  (加串器)     │     │        ────► CSI-2 │
└──────────────┘    └──────────────┘     │           到SoC   │
  (短距 D-PHY)      (长距 A-PHY)          └──────────────────┘
```

车载场景的典型拓扑是：摄像头端用短距 D-PHY 接传感器，经过加串器 (serializer) 转成 A-PHY 在同轴线上跑 10 多米，到网关处再经解串器 (deserializer) 还原为 CSI-2。TI、Maxim（ADI）是这个市场的主要芯片供应商。

## <span class="blue"> 本节总结

| 要点 | 内容 |
|------|------|
| D-PHY 信号构成 | 1对差分时钟 + 1~4对差分数据，源同步架构 |
| 双模式设计 | LP（单端，&lt;10Mbps，控制）和 HS（差分，最高2.5Gbps/lane，数据） |
| LP 状态机 | LP-11(Stop) → LP-01 → LP-00(HS-Rqst) → HS，切换有固定时序约束 |
| 带宽计算 | 总带宽 = Lane数 × 速率 × 80%(有效载荷比)；4 Lane v1.2 ≈ 10Gbps |
| C-PHY 差异 | 3线无CLK设计，过渡编码，pin效率更高，2.5Gsym/s/lane |
| A-PHY 定位 | 车载长距(15m)，16Gbps，带FEC，需要加串/解串芯片 |
| 关键设计约束 | 走线等长(&lt;0.2mm)、差分阻抗100Ω、远离开关噪声源 |
| 效率陷阱 | HS突发模式对小包不友好，适合连续大数据流（图像/视频） |
