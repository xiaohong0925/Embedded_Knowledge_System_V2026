# F. 前沿高速串行

> SerDes 通识与当代高速串行协议：PCIe 演进、CXL、JESD204C、USB4/Thunderbolt、Aurora

## 板块定位

当速率进入 10 Gbps 以上，总线物理层只剩一种技术：SerDes。本板块是 B 扩展的"未来仓"——收两类内容：一是所有高速链路共用的 SerDes 通识（均衡、眼图、抖动、信道预算），二是嵌入式正在或即将接触的当代串行协议与内存语义互连。

定位是**认知与选型**而非操作手册：这些协议的驱动大多由 SoC/FPGA 厂商提供，工程师的核心场景是方案评审、器件选型、与 SI/硬件同事对话、判断技术代次与行业阶段。读懂这一板块，数据手册的 SerDes 章节、原厂的眼图报告、产品路线图对你不再是黑话。

16.1 是其余各篇的共同地基，必须先读；16.2 与 16.3 是"演进与互连叙事"组（PCIe 走到哪、内存语义怎么跑在 PCIe 之上），16.4~16.6 是三个垂直场景协议，按产品需要选读。

与 D 板块的分工：D.10 PCIe 系列（10.1~10.5）讲**怎么把链路做稳定**（训练、排障、AER、CXL 生态认知），F.16.2/16.3 讲**技术走到哪一步、机制为什么变成这样**——工程篇与演进篇互补，读法是先 D 后 F。

## 先修与后续

- **先修**：B.5.1 的差分概念（RS-485 是低速差分，这里是 GHz 差分，同一家技术）；D.10.1 PCIe 物理层（链路/lane 组织）；16.2/16.3 另需 D.10.4/10.5 作先修。
- **后续**：D.14.4 车载 SerDes（GMSL/FPD-Link/A-PHY）是这套通识在车载场景的标准化落地；E.15.5 数通整机的背板设计直接引用信道预算方法，并把 Aurora/JESD204C/CMIS 组进整机。

## 内容边界

不教信号完整性设计（S 参数、IBIS-AMI、仿真工具链）——那是 SI 工程师的专业领域；本板块止于"识读与对话能力"。协议驱动开发细节归 D 扩展与 D.10 对应篇。
