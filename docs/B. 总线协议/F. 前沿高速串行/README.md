# F. 前沿高速串行

> SerDes 通识与下一代高速串行协议：JESD204C、USB4/Thunderbolt、Aurora

## 板块定位

当速率进入 10 Gbps 以上，总线物理层只剩一种技术：SerDes。本板块是 B 扩展的"未来仓"——收两类内容：一是所有高速链路共用的 SerDes 通识（均衡、眼图、抖动、信道预算），二是嵌入式正在或即将接触的前沿串行协议。

定位是**认知与选型**而非操作手册：这些协议的驱动大多由 SoC/FPGA 厂商提供，工程师的核心场景是方案评审、器件选型、与 SI/硬件同事对话。读懂这一板块，数据手册的 SerDes 章节和原厂的眼图报告对你不再是黑话。

## 先修与后续

- **先修**：B.5.1 的差分概念（RS-485 是低速差分，这里是 GHz 差分，同一家技术）；D.10.1 PCIe 物理层（链路/lane 组织）。
- **后续**：D.14.4 车载 SerDes（GMSL/FPD-Link/A-PHY）是这套通识在车载场景的标准化落地；E.15.5 数通整机的背板设计直接引用信道预算方法。

## 内容边界

不教信号完整性设计（S 参数、IBIS-AMI、仿真工具链）——那是 SI 工程师的专业领域；本板块止于"识读与对话能力"。协议驱动开发细节归 D 扩展与 D.10 对应篇。
