# B-D.12.1 工业以太网总览：EtherCAT / PROFINET / EtherNet-IP 版图

> 所属章节：第五部 B. 总线协议 > D. 专用网络总线
>
> 难度：[B] | 预计阅读时间：35 分钟

## 本节导读

CAN 解决了可靠性和确定性，但有两个天花板：1 Mbps（FD 下 8 Mbps）的带宽和逐帧仲裁带来的规模上限。当一条产线要挂几百个伺服和 IO、控制周期压到 250 µs 以下、还要传诊断数据和参数时，工程师把视线转向了以太网——带宽大三个量级、布线标准化、IT 基础设施可复用。但标准以太网是非确定性的：交换机排队、CSMA/CD 的历史包袱、TCP 重传，每一样都和实时控制冲突。工业以太网就是"在以太网上重做确定性"的一组方案，而且不止一种—— EtherCAT、PROFINET、EtherNet/IP、POWERLINK、CC-Link IE、Sercos III 各自走了不同的技术路线。

本节是 D.12 组的总览：不深入任何一个协议的帧格式（那是 12.2~12.4 的事），而是建立版图认知——每个方案怎么解决确定性、硬件代价是什么、生态被谁把持、选型时按什么维度收敛。读完你应该能给出一个项目"该用哪种工业以太网"的初步判断，并说清楚理由。

本节覆盖：工业以太网要解决的三个确定性问题、四大主流方案的技术路线对比、从站芯片与主站协议栈的生态格局、CANopen 应用层的跨协议复用（CoE）、TSN 作为收敛方向、按行业与约束的选型矩阵。

## 工业以太网要解决什么

把标准以太网搬进控制回路，要补三个缺口：

1. **确定性时延**：控制帧必须在可预期的窗口内到达。标准以太网的交换机存储转发队列深度不可控，时延抖动轻松超过一个控制周期。
2. **同步**：多轴运动要求所有从站在同一时刻采样、同一时刻输出，需要全网时钟同步到 µs 甚至 ns 级。
3. **与 IT 流量共存**：工厂网络里控制流量和诊断、视频监控、MES 上报跑在同一套布线里，实时流量不能被大流量冲垮。

四个主流方案对这三个问题的回答方式完全不同，这是理解版图的主线。

## 四大方案的技术路线

### EtherCAT：集总帧，一帧过全网

EtherCAT（IEC 61158/61784，ETG 协会）的机制最激进：主站发一个大的以太网帧，帧里按顺序塞着所有从站的过程数据；帧像火车一样依次穿过每个从站，从站硬件（专用 ESC 芯片）在帧经过自己的瞬间读出输出数据、插入输入数据——"processing on the fly"，全程不存储转发。帧绕完一圈回到主站，一次通信周期完成。

- 确定性来源：没有交换机排队，延迟由帧长度和从站数量精确决定；从站硬件处理引入的延迟是固定的几十 ns 级。
- 同步：分布式时钟（DC）机制，主站测量并补偿各从站的时钟漂移与传播延迟，全网同步到 <1 µs，轴间 <100 ns（详见 12.3）。
- 硬件代价：从站必须用 ESC 专用芯片（ET1100/ET1200、LAN9252、AX58100 等）；主站是纯软件的，普通网卡即可。
- 生态：ETG 会员制，从站芯片由 Beckhoff 授权体系控制；主站侧有商业栈（Acontis、KPA）和开源 IgH EtherCAT Master（Linux，12.5 实战用它）。
- 典型地盘：运动控制、机器人关节、半导体设备——轴多、周期快、拓扑呈线/树形的场景。

### PROFINET：交换机里做优先级

PROFINET（IEC 61158，PI 协会）走标准以太网兼容路线，分三档实时等级：

- **PROFINET NRT**：标准 TCP/UDP，非实时，用于参数和诊断。
- **PROFINET RT**：实时帧用以太网类型 0x8892 直发，跳过 TCP/IP 栈，靠 VLAN 优先级（IEEE 802.1Q）在交换机里插队。周期 1~10 ms，不需要特殊硬件。
- **PROFINET IRT**：等时同步实时，网络按时间片调度，需要带 IRT 功能的专用交换机芯片（ERTEC），周期可到 250 µs 以下，抖动 <1 µs。

- 确定性来源：RT 靠优先级排队，IRT 靠时间片调度与硬件。
- 生态：西门子主导，PLC 世界的事实标准；从站芯片 ERTEC/标准 MAC 均可（按档位）。
- 典型地盘：汽车产线、流程工业、以 PLC 为中心的工厂自动化。

### EtherNet/IP：标准以太网上的 CIP

EtherNet/IP（ODVA 协会）是"标准以太网 + CIP 应用层"：实时 IO 数据走 UDP 多播（Implicit Messaging），参数诊断走 TCP（Explicit Messaging）。不加硬件加速时确定性在 1~10 ms 级，靠 QoS 和网络规划保证。

- 确定性来源：主要靠工程手段（专用网段、IGMP 管理、QoS），协议本身不改 MAC 层；CIP Sync（IEEE 1588 PTP）提供 µs 级时钟同步。
- 硬件代价：零——纯标准以太网芯片。
- 生态：罗克韦尔（Rockwell）主导，北美市场强势。
- 典型地盘：北美工厂自动化、过程控制、离散制造的 PLC 网络。

### POWERLINK 与 CC-Link IE：另外两条路线

- **Ethernet POWERLINK**（EPSG）：标准以太网硬件，主站轮询制——一个周期内主站依次点名从站，避免冲突实现确定性。主站开源（openPOWERLINK），FPGA/ASIC 从站方案都有。奥地利 B&R 主导，欧洲机械装备常见。
- **CC-Link IE**（CLPA）：三菱主导的千兆工业以太网，TSN 版本（CC-Link IE TSN）是第一批商用 TSN 方案。日系设备与亚洲市场常见。

### 横向对比

| 维度 | EtherCAT | PROFINET RT/IRT | EtherNet/IP | POWERLINK |
|:---|:---|:---|:---|:---|
| 最小周期 | ~12.5 µs（实用 100 µs） | RT ~1 ms / IRT ~250 µs | ~1 ms | ~200 µs |
| 抖动 | <1 µs（DC 同步 <100 ns） | IRT <1 µs | ms 级 | <1 µs |
| 确定性机制 | 集总帧 + 硬件透传 | 优先级 / 时间片 | QoS + 网络规划 | 主站轮询 |
| 从站硬件 | 必须 ESC 专用芯片 | RT 标准 MAC / IRT 专用芯片 | 标准以太网 | 标准 MAC（FPGA 可选） |
| 主站硬件 | 标准网卡 | RT 标准网卡 / IRT 专用 | 标准网卡 | 标准网卡 |
| 开放性 | ETG 授权，IgH 开源主站 | PI 会员 | ODVA 会员 | 开源 |
| 强势生态 | 运动控制、机器人 | 西门子系产线 | 罗克韦尔系（北美） | B&R 系机械 |

## 应用层的跨协议复用：CoE

有一个能省一半学习成本的事实：**CANopen 的对象字典、PDO/SDO、CiA 402 伺服行规被 EtherCAT 原样继承**——EtherCAT 的 CoE（CANopen over EtherCAT）协议把 CANopen 帧装进 EtherCAT 数据报，伺服驱动器的对象字典（0x6040 控制字、0x6064 实际位置）在两条总线上完全一致。PROFINET 侧对应的运动行规是 PROFIdrive，概念同构（状态机 + 标准报文），索引不同但思想一致。

所以学习顺序有讲究：先把 D.11.4~11.5 的 CANopen 吃透，D.12 里就只剩"帧怎么跑"是新知识；反过来先在 EtherCAT 项目里摸过 CoE，再回头做 CAN 的伺服控制也只是换传输层。

## TSN：收敛方向

TSN（Time-Sensitive Networking，IEEE 802.1 族）是以太网标准自身的实时化：802.1AS 时间同步、802.1Qbv 时间感知调度、802.1Qbu 帧抢占等一组子标准，目标是把"确定性"从各家私有方案变成以太网的标配能力。OPC UA over TSN 被寄望成为统一的应用层。

对工程师的现实意义分两档：车载以太网已经把 TSN 当底座（D.14.1 展开）；工业领域 CC-Link IE TSN 已商用，PROFINET over TSN 在推进，但存量网络的私有方案会长期共存——TSN 是新设计和预研的必选项，不是替换现有 EtherCAT 网络的紧迫理由。

## 选型矩阵

| 项目约束 | 收敛方向 | 理由 |
|:---|:---|:---|
| 多轴伺服，周期 ≤1 ms，轴间同步 | EtherCAT | 集总帧 + DC 是为此设计；机器人/半导体设备事实标准 |
| 西门子 PLC 为中心的产线 | PROFINET | 生态锁定，与 TIA Portal 工具链一体 |
| 北美项目、罗克韦尔体系 | EtherNet/IP | 同上，生态锁定 |
| 预算敏感、IO 为主、周期 ≥1 ms | PROFINET RT / EtherNet/IP / Modbus TCP | 标准硬件即可 |
| 日系设备对接 | CC-Link IE（TSN） | 生态锁定 |
| 新架构预研、跨厂商统一 | OPC UA over TSN | 标准演进方向 |
| 与 CAN 节点混存 | EtherCAT + CAN 网关，或 CANopen | CoE 复用应用层，网关成熟 |

## 排障：总览层的误判

总览篇的"故障"是选型层面的误判，列三个高频的：

| 误判 | 后果 | 纠正 |
|:---|:---|:---|
| 以为 EtherCAT 从站可以用普通 PHY | 设计打回：集总帧透传必须 ESC 芯片 | 立项时确认从站芯片供货与授权 |
| 以为 PROFINET RT 能做 250 µs 多轴同步 | 性能不达标 | 需要 IRT 档 + 专用交换机，或直接换 EtherCAT |
| 以为工业以太网之间可以直连互通 | 现场集成失败 | 协议互不相同，跨协议必须用网关或上层 SCADA 汇聚 |
