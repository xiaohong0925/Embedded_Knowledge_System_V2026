# B. 低速外设接口

> 嵌入式系统基础通信总线：GPIO、PWM、ADC/DAC、I2C、SPI、UART、I3C

## 板块定位

嵌入式开发的日常 80% 在这 23 篇里：传感器是 I2C/SPI、调试口是 UART、电机是 PWM、执行器是 GPIO。这是 B 扩展唯一**建议所有方向读者通读**的板块——不论你去做机器人、消费电子还是 PCIe 卡，这组总线都是产品里数量最多、调试频率最高的通信方式。

同时它是后续所有高速/行业总线的"母题"：I2C 的开漏线与会在 CAN 仲裁里重现，SPI 的片选寻址会在 USB/PCIe 枚举里升级，UART 的差分演进（RS-485）就是工业总线的起点。这里学扎实，后面每个新协议只需学增量。

## 先修与后续

- **先修**：A 板块 1.1（总线通用词汇）；主线第二部设备模型（读各组"驱动框架"篇时）。
- **后续**：I2C 知识直接迁移到 B.6 I3C（演进）与 D.14.5 光模块 CMIS（工业变体）；B.5.3 的差分与 Modbus 寄存器模型是 D.11 CAN 的台阶；各组驱动框架篇指向 D 扩展的完整驱动写法。

## 选读建议

| 读者 | 建议 |
|------|------|
| 所有人 | B.2~B.5 全读，实战篇跟着做（均有无硬件后备路径） |
| 不用 I3C 的方向 | B.6 只读 6.1（知道它是什么、选型时想到它），6.2~6.4 用时再读 |
| 非工业方向 | B.5.3 RS-485/Modbus 可概读，记住"存在这个东西"即可 |

## 内容边界

各组"驱动框架"篇只讲该总线的框架结构与关键 API，**完整驱动写法**（probe 套路、regmap、中断与底半部）在 D 扩展；排查内容集中在各组调试篇，正文不重复。
