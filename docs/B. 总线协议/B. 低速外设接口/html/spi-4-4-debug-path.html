选择一种证据，高亮它实际覆盖的路径。高亮表示“这项观察能支持到哪里”，不表示当前板卡已经实测通过。

正常 ID：本次端到端事务符合已知答案

覆盖：用户命令、spidev、Core、控制器、外部收发路径、Flash 应答和用户结果。必须同时满足工具成功返回与 RX[1]～RX[3] = EF 40 18。

不能覆盖：长期稳定、其他速率、其他板卡、接收端模拟裕量，以及所有产品访问。

下一转向：若 ID 不符，根据异常选择回环、数字帧或模拟波形；恢复任何临时状态后都要回到本项复测。

文字兜底：五种证据的覆盖范围与盲区
  • 正常 ID：覆盖本次完整事务；不能证明长期稳定、其他速率或模拟裕量。
  • 内部回环：覆盖用户传输、Core 和控制器提供的内部回环路径；不经过外部引脚、接线、CS 和 Flash。失败时查控制器配置，成功而正常 ID 仍错时抓完整数字帧。
  • 外部短接：覆盖短接点以内的当前收发路径；不证明 Flash 应答，也不证明短接点之外或其他 CS、速率正常。结束后断电移除短接并复测正常 ID。
  • 数字帧：覆盖探针处的 CS、SCLK、MOSI、MISO 位流关系；不证明用户缓冲区交付或接收端模拟裕量。线上 ID 正确而用户结果错误时，回查软件长度、前导和偏移。
  • 模拟波形：覆盖探针处的电平门限、边沿和采样窗口；不证明命令、位序、帧边界或 ID 内容。数字帧与波形都正确而用户结果错误时，回查 RX 交付路径。
