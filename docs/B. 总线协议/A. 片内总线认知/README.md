# A. 片内总线认知

> SoC 内部互连总线：APB、AHB、AXI、TileLink、NoC、CHI、UCIe

## 板块定位

B 扩展唯一不教"连线"的板块——这里的总线藏在 SoC 封装内部，你看不到也摸不着，但每天都在跟它打交道：`ioremap` 映射的地址、DMA 缓冲的一致性、设备树 `reg` 属性、性能异常的带宽竞争，答案全在片内互连里。

把它放在 B 扩展第一站的原因：后续每个板块的协议（I2C 的 ACK、PCIe 的 TLP）都建立在"主设备发事务、从设备响应"这套词汇上，而这正是 AMBA 家族定义的通用语言。先在这里建立认知，后面学的每个新总线都只需要关注"它改了什么"。

## 先修与后续

- **先修**：数字电路基础（知道寄存器、时钟、总线是什么）即可，无协议前置。
- **后续**：A.1.2 的 AXI 事务思想与 D.10 PCIe 的 TLP 同源（读写请求/完成/乱序），是 PCIe 的"片上镜像"；A.1.3 的一致性是 F 板块 CXL 内存语义的直接前提。

## 内容边界

本板块讲认知与机制，不教具体总线控制器的驱动写法——片内互连对驱动开发者大多透明，需要动手的地方（DMA API、内存映射）在 D 扩展对应篇展开。
