# E. 综合实战

> 多总线系统集成与行业应用：机械臂、AGV、人形机器人、整机总线架构

## 板块定位

单个总线学会 ≠ 会设计整机。真实产品是十几种总线的协同：机械臂关节内是 SPI 编码器、关节间是 CAN/EtherCAT、视觉是 MIPI/USB、调试是 UART——选型错一个，要么带宽不够，要么实时性崩，要么成本爆炸。本板块用行业整机案例回答架构问题：**为什么这个产品选这几种总线、各自承担什么角色、带宽/实时性/成本怎么权衡**。
