## 模块概述

本模块是嵌入式 Linux 知识体系的**核心工程层**，聚焦设备驱动与总线协议的系统化设计。从字符/块/网络设备驱动框架，到 I2C/SPI/UART/PCIe/CAN 等全谱系总线协议，覆盖驱动开发从入门到精通的完整生命周期。

完成本模块，意味着具备了嵌入式 Linux 驱动开发的核心竞争力，能够为任何 SoC 平台编写、适配和调试设备驱动。
