## 核心问题

启动时间怎么优化？

## 本章简介

核心链路：BootROM → SPL → U-Boot → Kernel → Init → Application

本章追踪一个嵌入式设备从上电到用户界面可用的完整启动链，不是简单罗列优化技巧，而是回答一个关键问题：每一毫秒启动时间去了哪里？以及你愿不愿意付出代价来消灭它？

典型启动时间分布（因平台而异）：

- BootROM：~50ms（固定，通常无法优化）
- SPL：~200ms（可变，可裁剪）
- U-Boot：~500ms（可变，可精简驱动）
- Kernel：~800ms（可变，并行初始化）
- Init：~1200ms（可变，服务按需启动）
- Application：~2000ms（可变，延迟加载）
