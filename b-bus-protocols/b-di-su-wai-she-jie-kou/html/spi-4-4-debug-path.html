SPI 调试不是固定清单，按当前输出选下一步

同一笔 JEDEC ID：TX = 9F 00 00 00；有效 ID = EF 40 18。点击你实际看到的结果。

RX 全 00／FF：先确认测的是正确对象

下一步：核对原理图、实际连接、CS 和 pinmux，再抓完整数字帧。

不能推断：不能仅凭数值宣布 Flash 损坏、某根线固定电平或软件栈全部正常。

有用命令：dmesg | grep -i spi

不看图时的完整分支
  • 工具不存在：先编译或安装匹配版本，尚未开始验证 Flash。
  • 没有设备节点：查 DTS、控制器注册和驱动绑定。
  • 调用失败：保留原始错误，查权限、节点、配置和绑定。
  • 全 00／FF：先核对实际连接和完整帧，不把现象当根因。
  • ID 错误或错位：比较线上帧与用户 RX，区分采样、帧边界和软件偏移。
  • ID 正确：只建立当前事务基线，再按需做速率和产品验证。
