## 本书定位

本书覆盖嵌入式 Linux 全栈知识，从硬件层到应用层，从系统启动到内核机制，从设备驱动到安全加固。全书采用 **BIEM 深度分级** 体系，不同水平的读者可以找到对应的切入路径，逐步建立起对嵌入式 Linux 完整、系统的认知地图。

## 核心读者

- **BSP / 内核驱动工程师**（主力读者）
- **想深入理解 Linux 内核的嵌入式开发者**
- **希望从应用层下沉到系统层的全栈工程师**

## BIEM 深度分级

全书采用 **BIEM（Beginner → Intermediate → Expert → Master）** 四级深度标注，帮助读者按需切入。

| 级别 | 代号 | 定位 | 内容特征 | 阅读建议 |
|:---:|:---:|:---|:---|:---|
| **B** | Beginner | 入门建立认知 | 生活类比、基础命令、概念速查，**不涉及内核源码** | 零基础或跨方向读者从这里开始 |
| **I** | Intermediate | 理解机制与框架 | 数据结构、调用链、API 用法，可阅读伪代码与框架逻辑 | 能看懂内核设计思想，但暂时不深究源码行号 |
| **E** | Expert | 源码级深挖 | 真实内核源码（Linux 5.15/6.1 LTS）+ 关键行注释，逐行带读 | 带着问题追踪源码，理解每一行的设计意图 |
| **M** | Master | 扩展与前沿 | 历史演进、未来趋势、异构/虚拟化等探索性内容，**可独立跳过** | 关注架构演进、行业前沿和复杂场景设计 |

> **阅读提示**：章节标题后的 `[B→I]`、`[I→E]`、`[E→M]` 表示该章的深度跨度。  
> 小白可从 B 级切入，高手直接跳到 I/E 级，大师关注 M 级扩展框。

## 学习路径推荐

### 路径一：小白入门（B → I）

**目标**：建立完整知识地图，能看懂内核机制，能写基础驱动。

1. **通读第 I 部**（第 1–6 章）—— 从硬件到系统启动的完整链路，建立全局认知。
2. **选读第 III 部**（第 16–20 章 B 级部分）—— 了解常见外设和总线接口的基础知识。

完成路径一后，你将具备：
- 搭建完整的嵌入式 Linux 开发环境
- 理解交叉编译、Bootloader、内核编译、根文件系统的工作流程
- 能编写简单的 GPIO / LED 驱动程序

---

### 路径二：内核工程师进阶（I → E）

**目标**：具备内核子系统源码级理解，能独立调试、优化、移植。

1. **通读第 II 部**（第 7–15 章）—— 深入内核九大核心子系统的源码级分析。
2. **选读第 III 部**（第 21–25 章 E 级部分）—— 深入 DMA、高速外设、工业总线等进阶驱动开发。

完成路径二后，你将具备：
- 逐行追踪内核关键路径（调度、内存、中断、网络）
- 使用 ftrace、perf、eBPF 等工具进行动态追踪
- 调试和修复内核级 Bug（崩溃、死锁、内存泄漏）

---

### 路径三：大师级深挖（E → M）

**目标**：复杂场景定制、安全加固、异构/虚拟化方案设计。

1. **通读第 IV 部**（第 26–31 章）—— 系统构建、部署、OTA、供应链安全。
2. **通读第 V 部**（第 32–38 章）—— 性能优化、实时性调优、功耗分析、前沿技术。

完成路径三后，你将具备：
- 设计复杂的嵌入式系统构建与部署流水线
- 进行系统级性能瓶颈分析与架构优化
- 掌握异构多核、虚拟化、边缘 AI 等前沿方向的系统设计能力

## 本地站点构建（MkDocs）

依赖（托管 Python 环境）：

```text
pip install mkdocs mkdocs-material pyyaml pypinyin
```

常用命令：

```text
python -m mkdocs serve   # 本地预览
python -m mkdocs build   # 构建到 site/，WARNING 应保持为 0
```

站点层自定义（2026-08-06 起生效，改 mkdocs.yml 前先读这段）：

| 配置 | 位置 | 作用 |
|:---|:---|:---|
| `toc.slugify: slugify_unicode` | `mkdocs.yml` | 中文标题锚点保留汉字；默认 slugify 会把汉字剥光只剩数字，导致中文锚点链接全部失效 |
| `hooks: tools/url_slug_hook.py` | `mkdocs.yml` + `tools/url_slug_hook.py` | 构建期把中文输出路径转写为短英文 URL，如 `/02-core-mechanism/ch11-device-model/11.1.1-platform-soc/`；规则：目录名查 `DIR_MAP` 英文对照表 → 小节文件保留编号前缀和英文单词 → 拼音兜底。**新增中文目录时必须在 `DIR_MAP` 补一行**，否则会落入拼音兜底 |
