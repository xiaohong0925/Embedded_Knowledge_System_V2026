    第4章：内核配置与编译¶

    所属：第 一 部 系统启动与运行 BIEM：[B] | 核心问题：怎么让内核支持我的板子？

    核心问题¶

    怎么让内核支持我的板子？

    本章简介¶

    U-Boot准备好后，下一个任务就是获取Linux内核源码，配置它以支持你的开发板，编译生成可启动的内核镜像。内核是操作系统的核心——它管理硬件资源、提供用户空间接口、调度进程。但你不需要在第4章理解这些内部机制，你只需要做两件事：让内核能跑在你的板子上，让内核能驱动你需要的硬件。

    如果跳过本章直接使用预编译内核镜像，当需要添加某个驱动支持（比如一个特殊的传感器）或裁剪内核体积（嵌入式存储有限）时，你将束手无策。本章的核心理念是”配置驱动，不是理解调度器”。学完本章，你应该能：从正确的地方获取内核源码、使用menuconfig找到并启用需要的驱动选项、理解=y/=m/n三种配置状态的含义、编译出能启动的内核镜像。

    前置知识：第1章（了解你的SoC型号，决定内核架构）、第2章（交叉编译工具链）、第3章（U-Boot将加载这个内核）。...
